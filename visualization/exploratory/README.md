# Exploratory notebooks

**Status: legacy, not maintained, not part of the pipeline and not tested.** They predate
the fixes described in the main README (for instance they use the old "CROSS" naming and the
genome-level P@k), import `scikit-learn-extra`, `seaborn` and `adjustText`
(`requirements-dev.txt`), and write to `figures/exploratory/`. Their numbers are not
the article's.

These are the original, working notebooks used while the analysis was being developed.
**They are not needed to reproduce the article.** Every figure that made it into the
manuscript is regenerated by `python run_pipeline.py figures`, walked through step by
step in `../main_figures.ipynb`; these notebooks are kept only so that the exploratory
analysis behind the paper, and the way the data was handled, stays inspectable.

They do not follow the two-stage convention: they read the Excel tables in
`results/metrics/` directly and render straight to PNG in `../../figures/exploratory/`. Their first
cell switches the working directory to the repository root, so all paths inside them are
root-relative.

| Notebook | What it does |
|----------|--------------|
| `compare_ref_vir.ipynb` | First pass at the model comparison on the reference set and on the unseen orders — the ancestor of Fig. 1, 2, 4, 5 and the supplementary per-layer plots. |
| `compare_pk_new_vir.ipynb` | P@k vs k for the unseen orders — the ancestor of Fig. 6. |
| `cross_virus_pk.ipynb` | Per-layer P@10 vs cross P@10 scatter for the Egovirales/Mriyavirales pair — the ancestor of Fig. 7. Needs `adjustText` and `seaborn`. |
